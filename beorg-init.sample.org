#+TITLE: beorg 配置
#+STARTUP: overview

这是 beorg 的 =init.org= 样例，最后核对日期为 2026-08-29。
它使用 beorg 3.39.0 引入的新搜索语法，因此需要 beorg 3.39.0 或更高版本。

使用时，将它复制到共享 Org 目录并命名为 =init.org=。如果已经有同名文件，先比较
差异，不要直接覆盖。完全退出再启动 beorg 可以重新加载配置；也可以打开 beorg REPL
并运行 =(load 'init)=。

* TODO 状态

这些状态必须和 Emacs 保持一致。

#+begin_src scheme
(set! org-todo-action-keywords '("TODO" "WAITING" "SOMEDAY"))

(set! org-todo-done-keywords
      '("DONE" "CANCELLED"))
#+end_src

* 状态日志和重复任务

将状态变化写入和桌面 Org 相同的抽屉。

#+begin_src scheme
(set! org-log-into-drawer "LOGBOOK")
(set! org-todo-repeat-to-state "TODO")
#+end_src

* 文件过滤

Agenda 和 Tasks 不应显示配置文件与归档文件。

#+begin_src scheme
(set! agenda-exclude-files '("init.org" "archive.org"))
(set! todo-exclude-files   '("init.org" "archive.org"))
#+end_src

* Tasks 视图

默认只显示活动任务，不显示 =SOMEDAY=。

#+begin_src scheme
(set! todo-default-filter "/(state:TODO OR state:WAITING) group:state order:>priority")
(set! badge-filter "o k")
#+end_src

如果版本低于 3.39.0，先升级 beorg，不要把这行换成未经核对的搜索语法。

* 编辑器工具栏

#+begin_src scheme
(set! editor-toolbar-items
  '(
    ("📅" (insert (date->string (current-date) "<~Y-~m-~d ~a ~H:~M>")))
    ("✅" (insert "- [ ] "))
    ("icon-left"  (backward-char))
    ("icon-right" (forward-char))
  ))
#+end_src

* 启动页面

#+begin_src scheme
(set! ui-start-tab "todo")
#+end_src

* 在 App 中创建捕获模板

模板使用 beorg 自带的界面管理，不放进 =init.org=。长按 Agenda、Tasks 或 Files
页面底部的 =+=，选择 =Manage Templates…=，然后创建两个模板：

1. =✅ 任务=
   - Save To：=tasks.org=
   - State：=TODO=
   - 保持默认的追加到文件末尾
2. =💭 想法=
   - Save To：=ideas.org=
   - 不设置 State
   - 保持默认的追加到文件末尾

将 =✅ 任务= 设为默认模板。修改后分别创建一个条目：任务必须进入 =tasks.org=
并带有 =TODO=；想法必须进入 =ideas.org=，而且不能带 TODO 状态。

* 其他 App 设置

请在 beorg 界面中检查：

- Dropbox 账号和同步目录
- 同步权限

这些设置不适合由本文件管理。
